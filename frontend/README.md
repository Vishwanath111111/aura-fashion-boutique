# Aura Atelier — Luxury Haute Couture & Fashion Boutique

A production-ready Next.js client demo built by **VJ Web Studio**.

## Features
- Dynamic Lookbook Catalog filtering
- Quick View Modal with Size Selection
- Integrated Direct WhatsApp Ordering Concierge
- Instant Private Appointment Request Form
- Responsive & Accessible UI built with Next.js 15, Tailwind CSS & Framer Motion

## Getting Started
```bash
npm install
npm run dev
